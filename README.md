# Database Automation Framework

## Overview
This project automates routine database operational tasks such as health checks,
slow query detection, and backups using Python, Bash, and cron.

## Features
- Database health monitoring
- Slow query detection
- Automated backups
- Centralized logging
- Cron-based scheduling

## Tech Stack
- Python
- Bash
- SQL
- Linux
- Cron

## How to Run
1. Configure database details in config/db_config.yaml
2. Install dependencies: pip install -r requirements.txt
3. Run scripts manually or via cron

## Use Case
Designed to reduce manual database operational effort and improve reliability
in production environments.
